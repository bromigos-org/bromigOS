# live/

The Wick has no world, so this folder is empty. Without `live/world.toml`, the live layer
draws the den: the Wick's wallpaper, brought to life.

A world theme, such as Mire, puts its `world.toml`, `actors/` and `sounds/` here.
[docs/theming.md](../../../docs/theming.md) describes the format.
