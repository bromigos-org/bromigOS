# sounds/ (reserved)

This folder is reserved for the theme's interface cues, such as the blip, chirp, alert
and sweep, for the live layer and VECTOR. Nothing reads it yet. For now the cues come
from the live layer's own `sounds/`.

A world's ambient sounds, such as Mire's frogs, live in its `live/sounds/` instead. See
[docs/theming.md](../../../docs/theming.md).
