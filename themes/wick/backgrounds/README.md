# backgrounds/

This folder is empty for the Wick. The Wick's wallpaper is the den, a painted radio room,
and the `bromigos-desktop` package ships it (`desktop/wallpaper/`). `bromigos wallpaper`
switches between the den's variants.

A world theme, such as Mire, keeps its layered art here, as `layers/NN-name.webp`.
[docs/theming.md](../../../docs/theming.md) describes the format.
