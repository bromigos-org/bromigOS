# icons/

A theme can put its own bar icons here, such as `cpu.svg` or `ram.svg` in their four
states, and `emblem.svg`. A theme's own icon is used as it is, instead of the shared one.

The Wick needs none. The shared set in `theme/icons/` is drawn in the Wick's colours, and
every other theme gets it recoloured. [docs/theming.md](../../../docs/theming.md)
explains icons and the emblem.
