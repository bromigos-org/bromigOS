# widgets/

`layout.toml` here says where the den's focal points are (its screens and TVs, the window
and the station), so the desktop's panels keep off them, and holds the layout made for the
den ("Made for the Wick"). The colour themes draw this same den, so they use this file
too. The format is in [docs/widgets.md](../../../docs/widgets.md#layouts).

The panels' colours come from `[widgets]` in `colors.toml`. See
[docs/theming.md](../../../docs/theming.md).
