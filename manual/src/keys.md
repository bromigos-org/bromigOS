# Keys

Every key a new install has, grouped by what it's for.

- **Super** is the key with the Windows or logo symbol on it.
- The keys for windows use **Alt**, and so do everyday ones such as the launcher, the
  terminal and screenshots.
- The SHORTCUTS panel on the desktop lists every key, your own included.
  <kbd>Super</kbd>+<kbd>K</kbd> shows or hides it. Click a row to run it. Window, workspace
  and media keys only work from the keyboard.
- <kbd>Super</kbd>+<kbd>Shift</kbd>+<kbd>K</kbd> searches the keys by name.

To change a key, or give a key to something new, open **Settings › Shortcuts**. See
[Your own shortcuts](shortcuts.md).

### Windows

Window keys use **Alt**, as do everyday keys such as the launcher, the terminal and screenshots, unless you chose another main key ([Your own shortcuts](shortcuts.md#use-super-for-the-window-keys)). Windows tile: the first window takes the large space on the left, and each new one goes to the top of the stack on the right.

|---|---|
| <span class="keys"><kbd>Alt</kbd>+<kbd>C</kbd></span> or <span class="keys"><kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd></span> | Close the window. |
| <span class="keys"><kbd>Alt</kbd>+<kbd>F</kbd></span> | Make the window fill the screen, keeping the bar. Press again to undo. |
| <span class="keys"><kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd></span> | Make the window fullscreen, over the bar. Press again to undo. |
| <span class="keys"><kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>V</kbd></span> | Let the window float freely, or put it back in the tiles. |
| <span class="keys"><kbd>Alt</kbd>+<kbd>Enter</kbd></span> | Swap the window with the large one on the left. |
| <span class="keys"><kbd>Alt</kbd>+<kbd>J</kbd></span> | Move to the next window. |
| <span class="keys"><kbd>Alt</kbd>+<kbd>K</kbd></span> | Move to the previous window. |

### Workspaces

A workspace is a separate screenful of windows. There are ten, on the number keys.

| Keys | What it does |
|---|---|
| <span class="keys"><kbd>Alt</kbd>+<kbd>1</kbd> to <kbd>0</kbd></span> | Go to workspace 1 to 10. The 0 key is workspace 10. |
| <span class="keys"><kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>1</kbd> to <kbd>0</kbd></span> | Send the window to another workspace. You stay where you are. |
| <span class="keys"><kbd>Alt</kbd>+<kbd>S</kbd></span> | Show or hide the scratchpad, a hidden workspace that opens over the one you're on. |
| <span class="keys"><kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd></span> | Put the window on the scratchpad. |

### Lock, sleep and quit

| Keys | What it does |
|---|---|
| <span class="keys"><kbd>Super</kbd>+<kbd>L</kbd></span> | Lock the screen. Your password opens it again. |
| <span class="keys"><kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd></span> | Open the power menu: lock, suspend, log out, restart or shut down. |
| <span class="keys"><kbd>Alt</kbd>+<kbd>Esc</kbd></span> | Put the machine to sleep. This key runs `sudo`, so it only works if sudo doesn't ask for your password. Suspend in the power menu always works. |
| <span class="keys"><kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>Q</kbd></span> | Log out at once. Save your work first: open windows close without asking. |
